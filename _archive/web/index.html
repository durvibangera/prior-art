Query — boxes are ANDed, terms inside a box are ORed

Matching is whole-word: DRONE will not find "drones". Multi-word phrases (dashed) become their own ANDed row — a box ORs its words, so "UNMANNED AERIAL" inside one would mean UNMANNED or AERIAL.

2. Derive search profile

Reads the uploaded document and proposes its own search vocabulary and IP pillars — no hand-written profile needed. Review before saving, especially pillar status (claiming / out of scope / not ours) — the tool cannot know your business intent from the text alone.

3. Extract claims

Uses the ACTIVE profile (save one above first). Each claim is tagged by pillar; anything not marked "claiming" is excluded from search — shown here for the record, not searched.

4. Generate safe search questions

Every row shown here is generic public vocabulary — the inventive combination is never sent to the portal. Click "Run" to load a question straight into the query builder on the left.

5. Compare against claims → verdict

After harvesting and scoring (Results tab), compare every shortlisted document against each claim: anticipates / partial overlap / unrelated.
